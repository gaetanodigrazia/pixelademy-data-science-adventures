## Verifica dei criteri di accettazione
- **Given** l'output è vuoto, **When** valido, **Then** «Nessun output: usa print()».
- **Given** la riga 3 è errata, **When** valido (kind=lines), **Then** «La riga 3 del bollettino non è corretta: la console mostra …».
- **Given** righe in più o in meno, **When** valido, **Then** messaggio con il numero di righe attese.
- **Given** kind=numbers, **When** stampo testo extra, **Then** «Stampa soltanto il valore richiesto».
