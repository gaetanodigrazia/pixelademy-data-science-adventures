# US-03.1 — Esecuzione di Python nel browser (Pyodide) (#26)

## File creati o modificati
- `src/app/core/services/python-runner.service.ts`

## Decisioni e divergenze dal sorgente
`python-runner.service.ts` copiato dal sorgente (Pyodide 0.27.7 da jsdelivr, caricamento lazy, namespace isolato per esecuzione, retry dopo errore). `python.model.ts` era già in US-02.1. Il sorgente non ha spec del runner: `python-runner.spec.ts` usa un Pyodide finto (output, errori, namespace isolato, stato, retry); l'esecuzione con l'interprete reale non è testata in CI (serve la CDN).

## Verifica dei criteri di accettazione
- **Given** sono online, **When** premo Esegui, **Then** vedo l'output di `print()` nella console.
- **Given** c'è un errore Python, **When** premo Esegui, **Then** vedo il messaggio d'errore in rosso.
- **Given** due esecuzioni consecutive, **When** la seconda parte, **Then** non vede le variabili della prima (namespace isolato).

Controlli eseguiti prima della PR: `npm test -- --watch=false` (passati) e `npm run build -- --configuration development` (riuscita).
