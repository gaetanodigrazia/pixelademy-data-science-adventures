## Verifica dei criteri di accettazione
- **Given** il percorso è nel catalogo, **When** lo seleziono, **Then** vedo titolo, descrizione, icona, tag e le missioni nell'ordine di difficoltà.
- **Given** completo tutte le missioni, **When** eseguo il programma, **Then** stampa il bollettino atteso (output validato riga per riga).
- **Given** i test di contenuto, **When** li eseguo, **Then** le soluzioni di tutte le missioni passano con Python reale.
