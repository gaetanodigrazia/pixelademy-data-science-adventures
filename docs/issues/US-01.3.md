# US-01.3 — Generazione automatica dei content pack (#15)

- Milestone: `v0.1-Foundation` · PR: #91

## File creati o modificati
- `README.md`
- `package.json`
- `scripts/`
- `src/app/content/`

## Decisioni e divergenze dal sorgente
Lo script è copiato dal sorgente. Senza pack genera `PACKS = []` (la cartella `content/` ha un `.gitkeep`). Il file generato è in `.gitignore`; l'hook `prebuild` per `npm run share` arriva con US-09.3.

## Verifica dei criteri di accettazione
- **Given** un nuovo `content/<id>/pack.ts`, **When** lancio `npm run packs`, **Then** viene generato `core/data/packs.generated.ts` (non committato).
- **Given** `npm start/test/build`, **When** parte, **Then** `packs` viene eseguito in automatico (pre-hook).

Controlli eseguiti prima della PR: `npm test -- --watch=false` (passati) e `npm run build -- --configuration development` (riuscita).
