## Decisioni e divergenze dal sorgente
Il sorgente non ha CI: è un PO Improvement. Workflow `.github/workflows/ci.yml` (Node 22, cache npm, `npm ci`, test, build di sviluppo) su PR e push su main; badge nel README. La branch protection su main non è stata impostata: è una modifica alle impostazioni del repo, da confermare.

## Verifica dei criteri di accettazione
- **Given** una PR aperta, **When** la CI gira, **Then** esegue `npm ci`, `npm test`, `npm run build` e fallisce se uno fallisce.

Controlli eseguiti prima della PR: `npm test -- --watch=false` (passati) e `npm run build -- --configuration development` (riuscita).
