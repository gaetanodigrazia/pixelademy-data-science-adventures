# US-01.1 — Scaffold Angular 21 standalone (#13)

- Epic: E01 — Fondamenta e tooling (#1) · Milestone: `v0.1-Foundation` · Stima: M (3 SP)
- PR: #88

## Obiettivo
Progetto Angular 21 standalone con esbuild (`@angular/build`) e Vitest, per sviluppare e testare da subito.

## File creati
- `package.json`, `package-lock.json`: Angular `^21.2`, `rxjs`, `tslib`; dev: `@angular/build`, `@angular/cli`, `@angular/compiler-cli`, `typescript`, `vitest`, `jsdom`, `prettier`, `@fontsource/press-start-2p`. Script: `start`, `build`, `test`.
- `angular.json`: builder `@angular/build:application` / `dev-server` / `unit-test`; budget di bundle come nel sorgente.
- `tsconfig.json`, `tsconfig.app.json`, `tsconfig.spec.json`: TypeScript `strict`, template strict.
- `.npmrc` (`legacy-peer-deps=true`, workaround al bug dei peer di jsdom con npm 10), `.editorconfig`, `.prettierrc`.
- `src/index.html` (lingua `it`, font Press Start 2P), `src/main.ts`, `src/styles.css` (tema pixel-art: `--line`, `--text`, `--muted`, `--mono`, `--font`).
- `src/app/app.ts` (home vuota, `OnPush`), `src/app/app.config.ts`, `src/app/app.spec.ts` (smoke test).
- `public/favicon.ico`.

## Decisioni e divergenze dal sorgente
- `src/styles.css` è copiato per intero (tema globale e kit dei pulsanti/pannelli), perché le issue successive lo usano.
- Esclusi di proposito perché appartengono ad altre issue: `monaco-editor` e il suo CSS (US-03.3), router e rotte (US-01.2), script `packs`/`share` e hook `pre*` (US-01.3, US-09.3), Netlify/Docker (US-01.4), dipendenze `@napi-rs/canvas`/`@netlify/blobs` (E09/E10).
- `@fontsource/press-start-2p` è installato (serve allo script di anteprima in US-09.3); in pagina il font arriva dal link Google Fonts di `index.html`, come nel sorgente.

## Come verificare i criteri di accettazione
1. `npm ci && npm start` → http://localhost:4200 mostra il titolo «PIXELADEMY» (home vuota).
2. `npm test -- --watch=false` → 1 test passa.
3. `npm run build -- --configuration development` → build completata.
